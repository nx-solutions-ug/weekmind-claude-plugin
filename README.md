# Weekmind plugin for Claude

Claude Code plugin marketplace for [Weekmind](https://weekmind.app), the AI planner that schedules tasks and routines around your calendar. It contains one plugin, `weekmind`: a connection to the hosted Weekmind MCP server and a skill that teaches Claude how to plan with it. No server code is included.

```sh
/plugin marketplace add nx-solutions-ug/weekmind-claude-plugin
/plugin install weekmind@weekmind
```

Then run `/mcp`, choose `weekmind` and log in. Details: [plugins/weekmind/README.md](plugins/weekmind/README.md).
